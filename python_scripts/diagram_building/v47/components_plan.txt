Data Transfer Hub Architecture Diagram — Component Plan
=======================================================

Overview: AWS architecture showing a Data Transfer Hub system with a Customer's AWS Account
(containing authentication, AppSync, Lambda, Step Functions, DynamoDB, CloudFront, S3, Fargate)
and an AWS Managed Account (containing S3, ECR, and replication templates).
User connects from external, numbered circles 1-8 mark the flow.

Layout: Left-to-right with two main account sections side-by-side inside AWS Cloud.

=== ARROWS / CONNECTIONS ===

External flow:
- Arrow from left edge -> into Authentication (Amazon Cognito y-level)
- User -> Data Transfer Hub UI (arrow up)
- Data Transfer Hub UI vertical trunk -> up to Authentication bottom edge (no arrowheads)
- Data Transfer Hub UI -> AWS AppSync (arrow right, at AppSync y)
- Data Transfer Hub UI -> Amazon CloudFront (L-shape: right then down-right, waypoints)

Middle row flow:
- AWS AppSync -> AWS Lambda (arrow right, circle 4 above)
- AWS Lambda -> Step Functions left edge (arrow right, circle 5 above)

Upper row:
- AppSync -> DynamoDB (L-shape: up then right, waypoints routing right of Auth box, circle 8 above horizontal)

Step Functions -> external:
- CloudFormation -> AWS Fargate (arrow down from SF bottom edge)

Cross-account connections:
- Amazon S3 (managed) -> CloudFormation (arrow left, circle 6 in gap)
- Amazon ECR -> AWS Fargate (arrow left, circle 7 in gap)

Bottom row:
- Amazon CloudFront -> Amazon S3 customer (arrow right)
