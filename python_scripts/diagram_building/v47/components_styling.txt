=== ARROW STYLE ===
- Color: DARK (#1a1a1a)
- Width: 2px
- Style: solid
- End arrowhead: "arrow"
- Start arrowhead: None (except trunk which has no arrowheads)
- All arrows orthogonal (horizontal/vertical segments only)
- Use waypoints for L-shaped and multi-segment paths

=== NUMBERED CIRCLES ===
- Background: DARK (#1a1a1a)
- Text: WHITE (#ffffff)
- Size: 40px diameter
- Font size: FONT_BODY (16)
- COFFSET = 26 (radius + 5px gap + stroke/2)
- Placed adjacent to arrows with 5px visible margin
- Horizontal arrows: circle ABOVE (cy = arrow_y - 26)
- Vertical arrows: circle LEFT (cx = arrow_x - 26)
