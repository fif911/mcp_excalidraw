========================================================
FLOW DESCRIPTION
========================================================

The diagram shows a conversational AI avatar system:

1. Users interact with Avatar UI in the Terminal Hardware
2. Avatar UI sends audio to Spoken Language Identification
3. Spoken Language Identification → Speech-to-text → Conversational Engine (processing pipeline)
4. Conversational Engine communicates bidirectionally with Large Language Model for responses
5. Responses flow back: Conversational Engine → Text-to-speech → Avatar Engine → Avatar UI (real-time avatar generation)
6. Camera captures video → Person Detection → feeds into Conversational Engine
7. Knowledge Vector DB provides context to Conversational Engine ("get context")
8. LLM sends event notifications to Knowledge Vector DB
9. Customer's Data Sources feed Data Indexing Pipeline → Knowledge Vector DB
10. Notification Pipeline sends alerts to On-premise Systems
