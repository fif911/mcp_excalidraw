Data Transfer Hub Architecture Diagram — Component Plan
=======================================================

Overview: AWS architecture showing a Data Transfer Hub system with a Customer's AWS Account
(containing authentication, AppSync, Lambda, Step Functions, DynamoDB, CloudFront, S3, Fargate)
and an AWS Managed Account (containing S3, ECR, and replication templates).
User connects from external, numbered circles 1-8 mark the flow.

Layout: Left-to-right with two main account sections side-by-side inside AWS Cloud.

=== HIERARCHY ===

AWS Cloud (outermost)
├── Customer's AWS Account (left section, solid border)
│   ├── Authentication (dashed sub-section, upper-left)
│   │   ├── Amazon Cognito (icon + label)
│   │   └── OpenID Connect (icon + label)
│   ├── Amazon DynamoDB (icon + label, upper-right of account, outside Step Functions)
│   ├── AWS AppSync (icon + label, middle-left)
│   ├── AWS Lambda (icon + label, middle-center — outside Step Functions)
│   ├── AWS Step Functions workflow (pink solid border, right side of account)
│   │   ├── AWS Lambda (icon + label, upper)
│   │   └── AWS CloudFormation (icon + label, lower)
│   ├── Amazon CloudFront (icon + label, bottom-left)
│   ├── Amazon S3 (icon + label, bottom-center)
│   └── AWS Fargate (icon + label, bottom-right)
├── AWS Managed Account (right section, solid border)
│   ├── S3 replication component template (icon + label, top-left)
│   ├── DynamoDB replication component template (icon + label, top-right)
│   ├── Amazon S3 (icon + label, middle-left)
│   ├── ECR replication component template (icon + label, middle-right)
│   ├── Amazon ECR (icon + label, bottom-left)
│   └── ECR replication Docker image (icon + label, bottom-right)
External:
├── User (person icon + label, bottom-left outside AWS Cloud)
└── Data Transfer Hub UI (computer icon + label, left side outside Customer Account)

=== NUMBERED CIRCLES (1-8) ===

Circle 1: Near Amazon CloudFront (bottom area)
Circle 2: Left of AWS AppSync (middle row)
Circle 3: Above Data Transfer Hub UI (left side)
Circle 4: Between AppSync and Lambda (middle row)
Circle 5: Right of Lambda, entering Step Functions (middle row)
Circle 6: Between Step Functions and Managed Account (right side, mid area)
Circle 7: Between Fargate area and Managed Account ECR (bottom-right)
Circle 8: Above/left of DynamoDB (upper area)

=== ARROWS / CONNECTIONS ===

External flow:
- Arrow from left → into Authentication (Amazon Cognito)
- User → Data Transfer Hub UI (arrow up)
- Data Transfer Hub UI → Amazon CloudFront (arrow right, through circle 1)
- Data Transfer Hub UI → AWS AppSync (arrow up-right, through circle 2)
- Data Transfer Hub UI → Authentication (arrow up)

Middle row flow:
- Circle 2 → AWS AppSync (arrow right)
- AWS AppSync → circle 4 → AWS Lambda (arrow right)
- AWS Lambda → circle 5 → enters Step Functions area

Step Functions internal:
- Step Functions contains Lambda (top) and CloudFormation (bottom)
- CloudFormation → AWS Fargate (arrow down)

Cross-account connections:
- Circle 6: AWS CloudFormation → Amazon S3 (managed account, arrow left ←)
- Circle 7: AWS Fargate → Amazon ECR (managed account, arrow right)

DynamoDB connection:
- Circle 8: Arrow from AppSync area → Amazon DynamoDB (arrow right)

Managed Account internal:
- Amazon S3 → S3 replication component template (arrow up-left)
- Amazon S3 → DynamoDB replication component template (arrow up-right)
- Amazon ECR → ECR replication component template (arrow up)
- ECR replication Docker image (standalone, near ECR)

Bottom row:
- Circle 1 → Amazon CloudFront → Amazon S3 (customer account)
