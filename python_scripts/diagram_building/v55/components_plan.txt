LAYOUT OVERVIEW
================================================================================
The diagram shows an AWS architecture for SageMaker Unified Studio with ML
training and data lakehouse capabilities. Flow is left-to-right and top-to-bottom.

External actors on the left, AWS Cloud encompassing everything else.
