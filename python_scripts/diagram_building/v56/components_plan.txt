================================================================================
CONTAINER HIERARCHY (outside-in)
================================================================================

1. AWS Cloud (outermost)
   - SOLID teal border, AWS logo in header (HARD RULE: AWS Cloud is always solid)
   - Contains everything except "ML engineers" user icon

2. AWS Region (inside AWS Cloud)
   - Dashed teal border, flag/region icon in header
   - Contains all AWS services

3. Amazon SageMaker (inside AWS Region, top-left area)
   - Solid teal border, SageMaker icon in header
   - Contains: SageMaker Unified Studio + Sales Forecasting Project

4. Sales Forecasting Project (inside Amazon SageMaker, right portion)
   - Solid purple border, purple header text
   - Contains 2x2 grid: Database assets, Git repository, Studio IDE, Tools

5. ML capabilities (inside AWS Region, top-right area)
   - Solid teal border, brain/ML icon in header, "ML capabilities" label
   - Contains: Amazon SageMaker (brain icon + label)

6. Coding capabilities box (inside AWS Region, bottom-left area)
   - Solid dark/black border, coding icon in header
   - Contains: "Coding capabilities" label (header) + Amazon Q Developer (icon+label)

7. Amazon SageMaker Lakehouse (inside AWS Region, bottom-right area)
   - Solid teal border, header text "Amazon SageMaker Lakehouse"
   - Contains: Amazon Redshift Serverless, Storage sub-section, Catalog sub-section

8. Storage sub-section (inside Lakehouse, center)
   - Light gray background, "Storage" header text
   - Contains: Amazon S3

9. Catalog sub-section (inside Lakehouse, right)
   - Light gray background, "Catalog" header text
   - Contains: AWS Glue Data Catalog
