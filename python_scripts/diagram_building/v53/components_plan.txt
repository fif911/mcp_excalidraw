==============================================================================
FLOW DESCRIPTION
==============================================================================

Step 1: ML engineers authenticate via AWS IAM Identity Center
Step 2: Engineers access Amazon SageMaker Unified Studio which contains the
        Sales Forecasting Project (with Database assets, Git repository,
        Studio IDE, and Tools)
Step 3: Coding capabilities powered by Amazon Q Developer feed into Studio IDE
Step 4: ML capabilities via Amazon SageMaker handle model training/inference
Step 5: Data is managed through Amazon SageMaker Lakehouse (Redshift Serverless,
        S3 storage, Glue Data Catalog)
Step 6: Amazon SageMaker connects back to Lakehouse for data access (dashed line)
