AWS Step Functions Image Processing Architecture — Component Plan (v45)
========================================================================

OVERVIEW:
A mobile-to-cloud AI processing pipeline. A mobile client sends images through
AWS front-end services, which are then processed in parallel by AI services
via AWS Step Functions, with results stored back to S3.

SECTIONS (left to right, nested hierarchy):
1. External clients (leftmost, OUTSIDE AWS Cloud)
2. AWS Cloud container (outermost cloud boundary, gray solid border)
   2a. Front end sub-container (dashed gray border)
   2b. AWS Step Functions workflow container (pink solid border, INSIDE AWS Cloud)
       2b-i. Parallel processing sub-container (dashed gray border)
   2c. AI service icons (inside AWS Cloud, right side)

HIERARCHY:
- AWS Cloud (outermost) contains: Front end, Step Functions, AI services, API Gateway, branching arrows
  - Front end contains: Circles 1-3, Amplify, Cognito, S3
  - Step Functions contains: Parallel processing, Circles 5/6/7, text boxes below PP

  - AI services: Textract, Rekognition, SageMaker, Translate, Polly, S3 (output)
- External (outside AWS Cloud): People, mobile client, AWS SDK
