# Components Styling Specification - Data Transfer Hub

- Size: 1500 x 900
- Background: white

## Containers

### AWS Cloud (outer boundary)
- Border: solid, #545B64 (dark gray), stroke-width: 2
- Corner radius: 8
- Fill: transparent (white)
- Header: AWS logo icon (32x32) + "AWS Cloud" text in black, font-size: 20
- Position: x=20, y=20, w=1460, h=860

### Customer's AWS Account
- Border: solid, #545B64 (dark gray), stroke-width: 2
- Corner radius: 8
- Fill: transparent
- Header: AWS Cloud/Account icon (32x32) + "Customer's AWS Account" in black, font-size: 18
- Position: x=50, y=80, w=920, h=740

### AWS Managed Account
- Border: solid, #545B64 (dark gray), stroke-width: 2
- Corner radius: 8
- Fill: transparent
- Header: AWS Cloud/Account icon (32x32) + "AWS Managed Account" in black, font-size: 18
- Position: x=1010, y=80, w=450, h=740

### Authentication (sub-boundary, DASHED)

- Corner radius: 4
- Fill: transparent

- Position: x=80, y=130, w=320, h=200

### AWS Step Functions workflow (sub-container, PINK border)

- Corner radius: 4

- Header: Step Functions icon (32x32) + "AWS Step Functions workflow" in black, font-size: 16
- Position: x=640, y=120, w=300, h=370

## Icon Variant Notes
- Amazon Cognito: Architecture icon, 64px
- OpenID Connect: gray icon with curved arrows (custom or general identity icon)
- Amazon DynamoDB: Architecture icon, 64px, purple variant
- AWS Lambda: Architecture icon, 64px, orange variant
- AWS CloudFormation: Architecture icon, 64px, orange variant
- AWS AppSync: Architecture icon, 64px, pink variant
- Amazon CloudFront: Architecture icon, 64px, purple variant
- Amazon S3: Architecture icon, 64px, green variant
- AWS Fargate: Architecture icon, 64px, orange variant
- AWS Step Functions: Architecture icon (for header), 32px
- Data Transfer Hub UI: Resource icon or custom (computer/monitor)
- Amazon ECR: Architecture icon, 64px, orange variant
- S3/DynamoDB/ECR replication templates: Resource icons, orange
- ECR replication Docker image: Resource icon or custom
- User: General resource icon (person)

## Arrows
- Stroke color: #545B64 (dark gray)
- Stroke width: 2
- Style: solid with arrowhead
- Routing: L-shaped (elbowed) where needed, straight where possible
- Arrowhead: standard triangle

## Numbered Badges
- Shape: circle (dark)
- Background: #232F3E (AWS dark navy)
- Text color: white
- Font size: 14
- Circle diameter: 28
- Position: adjacent to the arrow, near the source end
- Border: none

## Font
- Container headers: 18-20px, black, bold
- Sub-container headers: 16px, black, bold
- Service labels: 14px, black, regular
- Below icons, centered

## Z-Order (bottom to top)
1. AWS Cloud container
2. Customer Account / Managed Account containers
3. Authentication / Step Functions sub-containers
4. Service icons and labels
5. Arrows
6. Numbered badges (topmost)

## Special Notes
- Step Functions workflow pink border is a prominent visual element - ensure it's clearly visible
- Authentication boundary is DASHED - do not make it solid
- AWS Cloud outer boundary is SOLID (per hard rule)
- The two main containers (Customer Account, Managed Account) are side by side with a gap
- User icon is outside and below the AWS Cloud boundary
- Managed Account elements are arranged in a 2-column, 3-row grid
- All icons should have their appropriate AWS category color background squares
