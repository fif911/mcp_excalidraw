- Background: white

## Icon Variant Notes
- Amazon Cognito: Architecture icon, 64px
- OpenID Connect: use custom identity icon (gray with orange arrows)
- Amazon DynamoDB: Architecture icon, 64px, purple variant
- AWS Lambda: Architecture icon, 64px, orange variant
- AWS CloudFormation: Architecture icon, 64px, orange variant
- AWS AppSync: Architecture icon, 64px, pink variant
- Amazon CloudFront: Architecture icon, 64px, purple variant
- Amazon S3: Architecture icon, 64px, green variant
- AWS Fargate: Architecture icon, 64px, orange variant
- AWS Step Functions: Architecture icon (for header), 32px
- Data Transfer Hub UI: Resource icon (computer/monitor)
- Amazon ECR: Architecture icon, 64px, orange variant
- S3/DynamoDB/ECR replication templates: Resource icons, orange
- ECR replication Docker image: Resource icon or custom
- User: General resource icon (person)

## Arrows
- Stroke color: #545B64 (dark gray)
- Stroke width: 2
- Style: solid with arrowhead
- Routing: L-shaped where needed, straight where possible
- Arrowhead: standard triangle

## Numbered Badges
- Shape: circle (dark)
- Background: #232F3E (AWS dark navy)
- Text color: white
- Font size: 14
- Circle diameter: 28
- Position: adjacent to the arrow, near the source end
- Border: none

## Font
- Container headers: 18-20px, black, bold
- Sub-container headers: 16px, black, bold
- Service labels: 14px, black, regular
- All labels below icons, centered

## Z-Order (bottom to top)
1. AWS Cloud container
2. Customer Account / Managed Account containers
3. Authentication / Step Functions sub-containers
4. Service icons and labels
5. Arrows
6. Numbered badges (topmost)

## Special Notes
- Step Functions workflow pink border is a prominent visual element
- Authentication boundary is DASHED - do not make it solid
- AWS Cloud outer boundary is SOLID (per hard rule override)
- Two main containers side by side with gap
- User icon outside and below AWS Cloud
- Managed Account elements: 2-column, 3-row grid
- All icons should have their appropriate AWS category color background squares
